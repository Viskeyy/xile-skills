# 停车场记录分析

分析用户提供的 csv 停车记录,生成 .md 报告,保存在 csv 同级目录,文件名含记录起止日期,如 `停车分析报告_2026-09-01_2026-09-15.md`。

## 字段与定义

- `actual_start` / `actual_end`:实际进场/离场时间,人工操作,是全部问题分析的对象
- `status = 0`:审批未通过,本次预约未生效
- `place = 0`:外部停车场;非 `0` 为内部停车场
- 超时:`actual_end - actual_start > 2 小时`
- 间隔过短:`< 1 分钟`
- 短时批量:同一分钟内 `≥ 3` 条记录的 `actual_start`(或 `actual_end`)相同或相近

阈值为默认值,用户另有指定时以用户为准。

## 步骤

1. **分类** — 每条记录恰好归入一类:
   - 审批未通过:`status = 0`
   - 正常数据:`actual_start` 与 `actual_end` 均存在,且不命中任何问题规则
   - 问题数据,命中任一规则:
     a. 缺少 `actual_start` 或 `actual_end`
     b. 间隔超时或过短(见定义)
     c. 短时批量操作(见定义)
     d. 其他可判定为人工误操作的异常,需写明判定依据

   完成判据:三类计数之和 = 记录总数,无记录未归类。

2. **指标** — 计算 4 项:记录总数;问题数据数及占比;正常数据数及占比;超时数据数(不分正常/问题)及其中问题数据的数量。

   完成判据:4 项齐全,占比可复算。

3. **问题分析** — 按上述 a–d 分类统计问题数据,每类给出数量与一句归类原因。进场时间与预约时间同日内的偏差属正常;跨日则归入 d。

   完成判据:每条问题记录都有类别与原因,各类之和 = 问题数据总数。

4. **结论** — 依次说明:数据缺口(审批未通过的不计入);可计算记录的总停车时长;外部/内部停车场数量与占比;整体总结。

   完成判据:四项齐全,报告已按命名规则落盘。
