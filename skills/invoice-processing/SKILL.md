# 发票信息识别及整理

本技能目录结构:

```txt
skills/invoice-processing/
├── SKILL.md                        # 本文件
├── scripts/gen_receipt.py          # 报销单生成脚本
├── scripts/gen_summary.py          # 月度汇总生成脚本
├── references/
│   └── 环境准备.md                  # Python 安装与依赖 (首次运行前)
└── assets/
    ├── 报销申请单模版.docx                 # 空白模版, 生成报销单时使用
    ├── 月度汇总模版.xlsx                   # 月度汇总版式参考 (含 2026 年 6 月数据示例), 生成汇总时使用
    └── 曹英辰报销申请单中轻（雄安）2026-7-9（请款申请未报）.docx  # 已完成示例, 版式与填写规范参考
```

## 通用原则

执行本技能的过程中, 遇到任何存疑的地方 (信息缺失、模糊、矛盾或不确定如何处理), 都必须停下询问用户, 确认后再继续。

识别与分类一律以发票内容为准, 忽略发票的文件名; 报销单中的人员归属以人员文件夹名称为准。

源发票目录是包含人员/类别文件夹的当月目录。源发票仍按人员/类别归档; 所有生成的报销单和月度汇总文件均直接保存在源发票目录下。生成报销单统一使用本技能 `assets/报销申请单模版.docx`, 月度汇总的版式统一参照 `assets/月度汇总模版.xlsx`。

## 步骤① 识别信息

从每张发票/收据中抽取以下 4 项信息:

- 发票编号
- 发票日期
- 购买方名称
- 总金额

总金额同时识别大写和小写价税合计, 两者一致才采信; 若不一致, 停下询问用户以哪个为准。

完成判据: 每张发票都抽齐上述 4 项; 无法抽取的逐条记下原因。

## 步骤② 分类入文件夹

文件夹结构固定为两级: 人员文件夹 / 类别子文件夹。不存在的自动新增。每张发票只归入一个类别, 放入对应人员的对应类别子文件夹。

- 餐饮费: 餐费
- 办公费: 除差旅费/交通费/快递费/餐饮费外的一切发票均归入此类, 如咖啡、水果、饮料、办公用品、名片/logo/标书制作费等
- 差旅费: 机票发票、机票行程单、高铁票、火车票、住宿费、退票费等
- 交通费: 打车费
- 快递费: 快递费

完成判据: 每张发票都归入且仅归入一个类别子文件夹, 且位于对应人员文件夹下; 无法分类的逐条记下原因。

## 步骤③ 排序

在每个人、每个类别内, 按排序逻辑排列:

1. 发票日期从远到近
2. 发票金额从小到大
3. 发票编号从小到大

完成判据: 全部发票满足上述三级排序。

## 步骤④ 生成报销单

为每个 "姓名+购买方" 组合各生成一份 .docx 报销申请单。

- 文件名为 "姓名" + "报销申请单" + "购买方名称" + "生成当天日期", 日期格式如示例 "2026-7-9"; 示例中的 "（请款申请未报）" 等备注后缀仅在有需要时附加
- 版式参照 `assets/` 中已完成示例, 输出位置见通用原则
- 发票按步骤②的类别、步骤③的排序逻辑排列后, 再写入模版
- 生成时使用 `scripts/gen_receipt.py` (见下)
- 有多少发票就填多少条记录, 不合并、不分离
- 实际金额一律以步骤①从发票中识别到的总金额为准, 不自行估算或改值
- 备注中每个类别前加序号 (如 "1、差旅费用（3711.00元）", "2、交通费用（419.50元）"), 序号按类别出现顺序从 1 递增
- 表格各列列宽在所有行中保持一致, 类别标题行与数据行使用相同的列宽; 内容过长时换行, 不截断、不挤压, 避免产生残缺

### 环境准备: Python 安装

Python 与依赖未就绪时, 安装与验证步骤见 `references/环境准备.md`。

### 使用生成脚本

`scripts/gen_receipt.py` 按模版生成报销单, 用法:

```bash
python3 scripts/gen_receipt.py --data data.json --source-dir "源发票目录" --output "输出文件名.docx" [--template 模版路径]   # macOS
python scripts/gen_receipt.py --data data.json --source-dir "源发票目录" --output "输出文件名.docx" [--template 模版路径]    # Windows
```

`--data` 为 JSON 文件, 结构见 `scripts/gen_receipt.py` 顶部说明。

### 快递费

运单记录为独立文件。若存在运单记录, 快递费发票需与之逐笔一一对应, 并写明始发地与送达地。

完成判据: 每个 "姓名+购买方" 组合各生成一份且直接位于源发票目录下, 记录数与发票数一致; 备注中类别序号连续且递增; 表格列宽一致、无残缺; 无法处理的发票/收据逐条记下原因。

## 步骤⑤ 月度汇总

将当月所有人的发票:

1. 先按人员分类, 再按类别分类
2. 每个 "人员+类别" 分组内, 在类别名称后加括号, 写该组的合计金额 (组内所有发票金额之和)
3. 组内按步骤③的排序逻辑排列, 保留编号、日期、总金额, 并附一句简要说明

Excel 中, 人员与人员之间以空行间隔; 类别与类别之间不再添加空行。版式 (字体、字号、对齐、列宽、行高) 统一参照本技能 `assets/月度汇总模版.xlsx`。生成时使用 `scripts/gen_summary.py` 和 openpyxl (依赖见 `references/环境准备.md`), 输出位置见通用原则。

`scripts/gen_summary.py` 用法:

```bash
python3 scripts/gen_summary.py --data data.json --source-dir "源发票目录" --output "月度汇总.xlsx" [--template 模版路径]   # macOS
python scripts/gen_summary.py --data data.json --source-dir "源发票目录" --output "月度汇总.xlsx" [--template 模版路径]    # Windows
```

`--data` 为 JSON 文件, 结构见 `scripts/gen_summary.py` 顶部说明。

完成判据: 当月全部发票都出现在汇总中; 每个分组合计金额 = 组内发票金额之和; 人员、类别间间隔清晰; 汇总文件直接位于源发票目录下。

## 步骤⑥ 交叉核对

在本次实际执行的步骤范围内核对发票数量一致: 识别的发票数 = 分类的发票数 = 报销单记录数 = 汇总的发票数 (未执行的步骤不参与核对)。不一致则停下查明原因并询问用户。

## 最后

汇总并逐条列出所有记下的问题 (未能识别的信息、无法分类的发票/收据、无法处理的发票) 及其原因。
