# 环境准备: Python 安装

首次在新机器上运行技能前, 先检测: macOS 用 `python3 --version`, Windows 用 `python --version` (或 `py --version`)。已就绪则直接装依赖。

若没有 Python 环境: **先停下询问用户**是否安装及用哪种方式, 不要擅自安装。Python 是系统级软件: Homebrew 安装脚本需远程下载并执行、Windows 安装需要管理员权限, 且用户可能有自己的偏好 (如 uv、pyenv、特定版本)。确认后按系统执行:

**macOS:**

```
# 方式一 (推荐): Homebrew, 若未安装先装 Homebrew
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"  # 需 sudo, 耗时长
brew install python

# 方式二: 命令行工具自带 python3 (新版 macOS 系统 pip 受限, 依赖安装可能需 --break-system-packages)
xcode-select --install
```

**Windows:**

```
winget install Python.Python.3.12 --accept-package-agreements --accept-source-agreements
# 安装完成后新开一个终端使 PATH 生效, 命令为 python (或 py)
python --version
```

**安装依赖 (Python 就绪后自动执行, 无需再询问):**

* `python-docx`: 生成报销单 (步骤④)
* `openpyxl`: 生成 excel 汇总 (步骤⑤), xlsx 无标准库支持, 必须安装

```
# macOS
python3 -m pip install python-docx openpyxl   # 若报 externally-managed 错误, 加 --break-system-packages
# Windows
python -m pip install python-docx openpyxl
```

验证: macOS `python3 -c "import docx, openpyxl; print('ok')"`, Windows `python -c "import docx, openpyxl; print('ok')"`, 输出 ok 即就绪。
