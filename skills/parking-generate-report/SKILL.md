# 停车周报一页纸 PDF

输入一份停车场分析 .md 报告 (通常由 parking-record-analysis 产出), 输出符合 56 园区模板的一页纸 A4 PDF. 保留在输入的 .md 报告的同级目录下

## 模板与资源 (单一事实源)

- 模板: `assets/56园区停车场_周报_模板.html` - 复制整个文件, 只替换内容, 不改 CSS; 效果参照 `assets/56园区停车场_周报_模板.pdf`
- 字体: `assets/fonts/TsangerJinKai02-W04.ttf` / `-W05.ttf`, 输出目录 `fonts/` 下已有则直接用, 缺哪个补哪个
- 主题: 羊皮纸底 `#f5f4ed`, 主题红 `#D42B2B`, 标签底 `#F0D8D2`, 衬线 TsangerJinKai02
- 输出目录: 源 .md 所在目录, HTML 与 `fonts/` 并存, 模板中两处 `url("fonts/…")` 保持相对路径不动

## 步骤

1. **提取事实** - 通读源 .md 报告, 抄录: 数据周期(周起止日期), 预约总数, 问题数据条数与占比, 正常数据条数与占比, 超时车辆数及其中人工误操作数, 问题分类明细(无进出场/缺离场/批量/时长异常各多少), 批量集群典型样本, 审批未通过数, 总停车时长, 内部/外部停车场占比, 结论

    完成判据: 模板中每个数字槽位(4 个指标卡, lead, 两栏列表, callout)都有对应事实, 全部取自源报告, 零编造

2. **填充模板** - 按槽位替换:

    - header: eyebrow/h1 不动, subtitle 写数据周期与核心议题, meta 写生成日期
    - metrics: 4 张指标卡(预约记录 / 问题占比 / 完整率 / 超时辆数)
    - lead: 一句话结论先行, 关键数字用 `.hl`
    - 左栏 "本周数据构成": 环形图 + dash 列表(问题/审批未通过/正常三类)
    - 右栏 "问题分析": 批量, 超时, 时长异常的佐证
    - callout: 本周结论(数据缺口, 总时长, 内外部占比) 环形图 SVG: `r=96`, 周长 `603.19`, 各弧 `stroke-dasharray = 占比×603.19`, 顺序问题 `#504E49`, 正常 `#D42B2B`(主题色), 审批未通过 `#C9C4B5`, 中心文本写总数.

    完成判据: 无遗留模板占位数字, 所有数字与源报告一致

3. **渲染落盘** - 文件名 `56园区停车场_周报_MMDD.html` / `.pdf`(MMDD 取数据周期结束日), 存源 .md 同级目录, 然后:

    ```
    mkdir -p fonts && cp -n "<skill 目录>/assets/fonts/"*.ttf fonts/   # 已有则跳过, 退出码 1 属正常
    weasyprint 56园区停车场_周报_MMDD.html 56园区停车场_周报_MMDD.pdf
    ```

    完成判据: 命令零报错, PDF 已生成, 输出目录 `fonts/` 下两个 ttf 齐备

4. **单页校验** - `mdls -name kMDItemNumberOfPages <pdf>` 必须为 1. 若为 2: 优先删最次要的 dash 列表项, 其次把 `body` 字号降至 11pt, 行高 1.35, 逐档收紧直至单页

    完成判据: 页数为 1, 渲染 stderr 无 `Font-face ... cannot be loaded` 警告 (有则字体已回退系统衬线, 视觉不同), HTML 与 PDF 同名成对存在于输出目录
