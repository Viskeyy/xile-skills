# invoice-processing

发票识别与报销整理工具。将发票图片或 PDF 放入指定目录，自动完成识别、分类、排序，并生成报销申请单（.docx）及月度汇总表（.xlsx）。

## 目录结构

```
2026年7月/
├── 张三/
│   ├── IMG_2381.jpg
│   ├── 滴滴行程单.pdf
│   └── ...
└── 李四/
    └── ...
```

## 环境要求

- Python 3.9 或更高版本
- 依赖包：`python-docx`、`openpyxl`

安装依赖：

```bash
# macOS / Linux
python3 -m pip install python-docx openpyxl

# Windows
python -m pip install python-docx openpyxl
```

如未安装 Python，技能将提示安装方式。详细说明参见 `skills/invoice-processing/references/环境准备.md`。

## 安装

将技能目录复制至 Agent skills 目录：

```bash
# 全局安装（所有项目可用）
cp -r skills/invoice-processing ~/.agent/skills/

# 项目级安装（仅当前项目可用）
cp -r skills/invoice-processing /path/to/project/.agent/skills/
```

安装完成后重启会话，输入 `/` 即可在技能列表中看到 `invoice-processing`。

## 目录规范

在当月目录下按人员建立子文件夹，放入发票原件（支持图片和 PDF）：

```txt
2026年7月/
├── 张三/
│   ├── IMG_2381.jpg
│   ├── 滴滴行程单.pdf
│   └── ...
└── 李四/
    └── ...
```

**人员归属规则**：以文件夹名称为准，不读取发票上的姓名信息。

**分类规则**：仅依据发票内容进行识别与分类，文件名不影响分类结果。

## 使用方式

在会话中提供目录路径及任务描述即可：

```txt
帮我处理 ~/Desktop/报销/2026年7月 里的发票
```

技能将按顺序执行以下步骤：识别 → 分类 → 排序 → 生成报销单 → 生成月度汇总 → 交叉核对。

**支持单独执行部分步骤**：

```txt
识别并分类归档发票，暂不生成报销单
仅重新生成 2026年7月 的月度汇总
仅生成「张三」的报销申请单
```

**存疑处理**：当遇到金额大小写不一致、发票内容模糊、分类归属不明等情况时，技能将暂停并等待确认，不会自行推断。处理完成后会输出所有未能处理的发票清单及原因。

## 输出

生成的文件直接写入源发票目录，发票原件移动至 `人员/类别` 子目录进行归档：

```txt
2026年7月/
├── 张三/
│   ├── 差旅费/
│   ├── 交通费/
│   └── 办公费/
├── 李四/
│   └── ...
├── 张三报销申请单XX公司2026-8-14.docx    # 每位员工每家购买方各一份
└── 2026年7月发票月度汇总.xlsx
```

### 发票分类

| 类别   | 适用范围                                               |
| ------ | ------------------------------------------------------ |
| 餐饮费 | 餐费                                                   |
| 差旅费 | 机票、行程单、高铁票、火车票、住宿费、退票费           |
| 交通费 | 打车费                                                 |
| 办公费 | 饮料、办公用品、名片/logo/标书制作费等                 |

### 排序规则

每位员工的每类发票按以下规则排序：日期（从远到近）→ 金额（从小到大）→ 编号（从小到大）。

## 脚本接口（可选）

正常情况下无需手动调用，技能会自动调用脚本。如需手动重跑，可按以下方式执行：

```bash
# 生成报销单
python3 skills/invoice-processing/scripts/gen_receipt.py \
  --data data.json --source-dir "2026年7月" --output "张三报销申请单XX公司2026-8-14.docx"

# 生成月度汇总表
python3 skills/invoice-processing/scripts/gen_summary.py \
  --data data.json --source-dir "2026年7月" --output "2026年7月发票月度汇总.xlsx"
```

**参数说明**：

- `--output`：仅接受文件名，不可包含子目录路径。输出文件保存至 `--source-dir` 指定的目录。
- `--template`：可选参数，指定自定义模版路径。默认为 `assets/` 目录下的标准模版。

### 数据格式

<details>
<summary>报销单（gen_receipt.py）</summary>

```json
{
  "name": "张三",
  "date": "2026-8-14",
  "total": "4130.50",
  "items": [
    {
      "category": "差旅费",
      "total": "3711.00",
      "rows": [["1", "6月19日", "940.00", "元", "机票 北京-厦门 SC2130"]]
    }
  ]
}
```

**约束**：
- 金额大写由脚本根据 `total` 自动转换，无需手动填写
- 每个类别在 `items` 中仅可出现一次，空类别应整项删除
- 报销单中的排版顺序由模版决定（固定为餐饮/办公/差旅/交通），`items` 中的顺序不影响输出
- 各类别的 `total` 之和必须等于顶层 `total`，否则脚本报错

</details>

<details>
<summary>月度汇总（gen_summary.py）</summary>

```json
{
  "month": "2026年7月",
  "records": [
    {
      "name": "张三",
      "category": "差旅费",

```

`records` 列表按自然顺序填写即可，分组、排序及合计由脚本自动处理。

## 常见问题

**报销单记录缺失**

脚本按发票数量生成对应记录条数，不进行合并。若出现缺失，请检查识别阶段的问题清单。

**金额有误**

一律以发票中识别的价税合计金额为准。当大小写不一致时，技能将暂停确认，不自行推断。报销单上的大写金额由脚本从小写转换生成，不依赖模型输出。

**修改模版后脚本报错**

`assets/` 中的模版文件依赖脚本的结构定位逻辑进行填充。修改模版版式会导致定位失败并报错（不会生成不完整的文件）。修改前请确认脚本中的 `NESTED_INDEX` 配置及"填写说明"定位逻辑。
